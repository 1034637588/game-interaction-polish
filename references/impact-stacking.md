# 有效叠加与强度调优

适用于强打击感、爆发、落位和高反馈演出。目标是在当前素材、设备和操作频率下找到强烈、清楚、有控制感且可重复的组合。不要预设效果少才高级，也不要把效果数量或最大参数等同于体验质量。

## 证据与边界

- [Sugiyama & Inoue，2026](https://www.jstage.jst.go.jp/article/digrajprocsummer/2026/0/2026_11/_article/-char/en)：24 人在特定 3D 攻击场景中比较震屏、停顿、慢动作及两种组合。0.1–0.2 秒条件下组合优于单效果，0.4 秒时组合优势消失。各条件共享部分基础击中特效；这是特定参数下的结果，不是纯粹从零反馈开始，也不是全品类时长标准。
- [Kao，2020](https://experts.illinois.edu/en/publications/the-effects-of-juiciness-in-an-action-rpg/)：3018 人的 ARPG 实验中，中/高反馈条件在多个体验指标上优于无/极端反馈。这里只依据机构摘要，不能据此确定最佳效果数量或具体幅度。
- [Kao 等，2024](https://people.csail.mit.edu/dkao/pdf/3613904.3642656.pdf)：1699 人的 ARPG 实验并不支持无条件放大反馈。作者指出大光球可能遮住连续攻击和命中结果，妨碍因果归属；这是讨论中的可能机制，不能写成已证实的唯一原因。

这些结果允许主动叠加强反馈，也要求验证相互作用。单次冲击更强、操作更顺、整段体验更满意是不同目标，不能互相替代。下面是据此提出的设计流程，不是研究确证的公式或通用最优解。

## 1. 建立一个明确的冲击锚点

选择当前场景最值得打磨的瞬间，定义“什么物体，以什么方式，受到什么力量”。例如机械锁舌咬合、宝石裂开、最后一列撞进卡槽。

拆开输入接受与实际接触。玩家按下制动时立刻得到按钮/装置响应，稍后到达落点才触发接触冲击。不要把等待结束后的大特效视作输入响应的替代。

## 2. 用互补层构建强反馈候选

| 层 | 主要贡献 | 与其他层配合时要看什么 |
| --- | --- | --- |
| 主体动作 | 力的方向、材质和质量感 | 位移/形变是否与接触一致，是否可被看见 |
| 时间强调 | 把接触瞬间凸显出来 | 局部停顿或短慢动作是否增强触感，是否拖住下一输入 |
| 接触形状/亮点 | 精确定位撞击 | 起点是否和真实落点一致，是否被泛光淹没 |
| 声音瞬态/主体 | 边缘、重量和材质 | 主音对齐接触，低频与碎屑层不互相遮蔽 |
| 镜头/触觉 | 把力量传递给玩家 | 方向、衰减和屏幕尺度是否适配，平台是否实际支持 |
| 粒子/空间传播 | 能量、规模和余韵 | 方向、密度、速度及传播范围是否帮助解释力量 |
| UI/环境回应 | 事件重要性与结果归属 | 在主体动作之后加强解释，不提前抢走焦点 |

以任务目标决定组合，不强制集齐所有层。强反馈请求应有完整的高强度候选，不能只提供几个低幅度装饰。某层被其他效果遮蔽时，先尝试调整相位、范围或频段，再判断保留价值。

停顿须说明实际暂停的对象或时间推进。保持一个形变姿态、给回弹加延迟和真正停止动作推进并不相同；实现和报告使用准确术语。

## 3. 编排接触前后，而非所有层同时拉长

- 接触前：速度、收缩、声能或局部光的变化形成预期；高频动作可缩短或省略显式蓄势。
- 接触瞬间：主体姿态、接触形状与主音指向同一事件锚点；镜头和触觉按需配合。
- 接触之后：碎片、回弹、环境反应与结果读取错峰展开。尾迹可以持续，输入不必一直等待。
- 恢复：明确下一次有效输入时机。反馈仍在播放时，可以保留操作能力；需要锁定时解释原因并验证时长。

同步指的是对齐因果和主要峰值，不表示所有声部、粒子与面板必须同时开始。短时峰值可以很强，尾部迅速收束；增强不必靠延长整个演出。

## 4. 分别控制强度的几个维度

记录关键参数，而非只设置一个未经解释的“强度系数”：

- 幅度：形变、位移、镜头偏移、光的明暗差与音量。
- 时长：接触保持、衰减、尾音和禁止再次操作的时间。
- 覆盖：局部目标、场景、全屏，以及声音的频段占用。
- 密度：同时出现的碎片、声部与变化数量。
- 频率：相邻操作间隔、反馈重叠，以及低谷和高潮的分布。

提高其中一项后，检查其余项是否需要重配。例如增加层数时保持单层短促；扩大空间传播时保留接触点；高频连续事件保留每次的主体确认，必要时合并装饰尾部。不能将低频大演出的参数直接套入每秒多次的事件。

## 5. 用对比寻找有效区间

根据任务大小选择少量有信息量的比较，避免穷举组合。

1. 固定测试事件、结果与素材。比较组合时固定无关时序和输入路径；相位或时长本身是研究对象时明确标记。
2. 围绕招牌瞬间准备温和、强烈和更靠近边界的候选；可以先粗调幅度，再调接触时长、尾部和重复频率。边界候选不意味着不受控闪烁、削波或故意让人不适。
3. 对重要的两层比较基础、仅 A、仅 B、A+B，判断组合是否提供新收益；再从完整组合中关闭一层，观察它是否仍有贡献。无需把每个候选都发展成完整游戏。
4. 同时看单次和重复操作。可用连续 10–20 次作为小型设计检查起点，这不是经过研究确证的充分样本或标准。
5. 分开记录冲击力、接触/结果识别、输入控制感和重复疲劳。出现冲击更强但操作更慢的候选时说明取舍，不用任意总分掩盖它。

有真人比较时交替或平衡展示顺序，记录设备、音量、输入方式与参与人数；没有真人时仅记录设计观察和待验证假设。未试听音频时，不判断音色、混音或跨通道协同已经成功。

## 6. 如何判断叠加开始失效

有意义的边界信号包括：主体反应被盖住、连续两次命中融为一次、各等级无法区分、声部互相遮蔽、迟迟不能继续操作、震动造成定位困难，或多次重复后明显想跳过。

发现问题时定位到具体层与参数：缩短尾部、错开结果 UI、压低装饰声、收紧震动范围、减少同一位置的重复亮形，或更换与材质不符的回弹。避免不加诊断地整体降强度。

没有识别收益不等于某层必然无用，它可能贡献情绪或连贯性；需要通过对比判断。性能预算超标也应标为工程限制，不能冒充审美结论。
