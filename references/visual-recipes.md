# 素材与动作配方

## 素材检查

先查看实际图片或图集，记录用途和约束：

| 项目 | 影响的决定 |
| --- | --- |
| 实际可见轮廓与透明边距 | 点击区域、视觉中心、缩放轴心、落位基线 |
| 分辨率与预期显示尺寸 | 放大上限、细节损失、纹理内存 |
| 材质、光向、透视与边缘风格 | 选用碎片、光效、阴影与声音是否协调 |
| 是否有独立层或序列帧 | 局部形变、遮挡、裂开与运动能力 |
| 图集裁切与邻接区域 | 遮罩、纹理重复、滤镜取样是否露边 |

输出“素材 → 角色 → 处理方式 → 约束”。例如机身保持稳定、转轮被窗口裁切、玻璃反光置于转轮前层、落位光留在窗口内部。

静态整图无法合理拆解时，选择局部遮罩、附加碎片或保留主体的反馈；不要用整图弹跳代替所有材质反应。缺少素材时按重要度提出补充项，并说明可运行的替代方案。占位或程序绘制资产须标记，不能假称正式美术。

## 质感选择

| 质感 | 动作与形状 | 音效方向 |
| --- | --- | --- |
| 轻脆晶体 | 短接触、锐利裂形、少量快速碎片、细短余光 | 明确瞬态、紧凑破裂、少量高频尾音 |
| 柔软弹性 | 体积感一致的挤压拉伸、延迟回弹、圆润形状 | 柔和起音、低中频弹动、轻短尾音 |
| 厚重机械 | 接触前速度变化、短位移、低幅快速衰减、硬落位 | 撞击主体、机构咔嗒、受控低频 |
| 魔法能量 | 向目标聚拢、接触爆发、轨迹与消散统一 | 聚能层、释放瞬态、匹配画面的音调尾声 |

质感来自多通道一致性，不需要每次同时使用表中所有手段。

## 事件配方

### 按压、释放与取消

按下立刻确认；提交动作遵循项目原有的按下或抬起语义。分别处理移出取消、拖动、禁用和触屏，不依赖悬停传达核心信息。触觉或音效不能掩盖目标本身无响应的问题。

### 接触、命中与破裂

明确接触点与运动方向。主体先表现受力，碎片继承合理方向，声音瞬态对齐接触。高频目标优先局部反馈，必要时合并装饰粒子；不可因合并视觉而丢掉业务事件。普通反馈不应持续遮住下一操作目标。

### 滚动、减速与落位

围绕已确定的最终目标编排速度与停靠。先保证落点、裁切与符号中心正确，再增加轻微回弹和落位声。重型机械不默认使用软糖式弹性。停止后清楚展示最终结果，避免装饰运动被误认成仍可改变结果。

### 揭晓与强调

逐步引导焦点，保持来源和目标可读。揭晓时长服务于信息与情绪；重复体验可按产品要求跳过或缩短，跳过后保留完整最终状态。未命中和无奖励也需要清晰完成反馈，不伪装成成功。

### 收集与抵达

展示来源、运动与目的地回应。装饰性粒子数量可以采样，不代表真实金额；实际入账由业务逻辑负责。多个物品可错峰或汇聚，抵达声按组节制播放。明确数值何时变化，避免声音、显示和真实状态矛盾。

## 编排表范例

以下仅为清脆宝石的起始方案，需依据素材和操作频率调优；阶段允许重叠。

| 锚点 | 相对时间 | 视觉 | 声音 | 输入/状态 |
| --- | --- | --- | --- | --- |
| 有效按下 | 0ms | 小幅压缩，确认目标 | 轻触，可选 | 不提前声明结果成功 |
| 外部确认破裂 | 0–50ms | 接触亮点与短形变 | 破裂瞬态对齐接触 | 标记该对象已处理 |
| 确认破裂 | 30–220ms | 锐利碎片散开并衰减 | 紧凑碎裂尾音 | 其他对象保持可操作 |
| 收集表现开始 | 约 100ms 起 | 代表性粒子飞向 HUD | 轻扫声，可选 | 不触发第二次入账 |
| 粒子抵达 | 依路径决定 | HUD 局部回应 | 短收集音，按组限流 | 与约定的数值更新时机一致 |
